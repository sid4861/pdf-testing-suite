<pdfsuite-pdf-viewer> · @pdfsuite/viewer · W-42

One viewer, any PDF, never a new tab

Any app drops in <pdfsuite-pdf-viewer> — or calls openPdf(source) — and the PDF opens in a pop-up over the current page. pdfsuite’s tabs use the same element. Features arrive one level at a time.

Sources it opens
File Blob ArrayBuffer Uint8Array URL data:application/pdf;base64,… bare base64 PDFDocumentProxy

A cross-origin URL needs CORS; without it the viewer says so and offers a new tab as the fallback. Base64 is decoded in chunks, with a size cap.

A web component — React, Vue or plain HTML
<script type="module">import '@pdfsuite/viewer'</script>

<pdfsuite-pdf-viewer
  src="/files/proposal.pdf"
  name="Home loan proposal.pdf"
  page="1" open>
</pdfsuite-pdf-viewer>

// or from code, any framework
const el = openPdf(base64String, { name: 'Statement.pdf' })
el.addEventListener('pdfsuite-close', done)
