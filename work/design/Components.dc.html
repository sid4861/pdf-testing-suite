Web components, any framework

Custom elements with Shadow DOM: an attribute, a property and an event are the whole contract, so React, Vue, Angular and plain HTML all use them the same way. pdfsuite builds the PDF viewer; the sheet and its error list come from sheetpane, a separate package pdfsuite depends on.

import '@pdfsuite/viewer'
import 'sheetpane'   // tag names illustrative — sheetpane names its own

export function SpecReview({ workbook, pdf, marks }) {
  const [cell, setCell] = useState(null)
  return (
    <>
      <sheetpane-sheet mode="view" source={workbook} marks={marks}
        oncellselect={e => setCell(e.detail)} />
      <sheetpane-errors marks={marks} />
      <pdfsuite-pdf-viewer source={pdf}
        page={cell?.page} open={cell != null} />
    </>
  )
}
Rules every element follows
  • Names start with pdfsuite-; events with pdfsuite-.
  • Strings go in attributes; files, arrays and callbacks go in properties.
  • Shadow DOM; theming through --pdfsuite-* custom properties and ::part() — Proof’s tokens are the defaults.
  • No framework inside; React 19 and Vue pass properties and events natively.
  • Nothing leaves the browser; files are read locally.
  • sheetpane owns the sheet and the error list; pdfsuite only hands it marks keyed by sheet and A1 cell.
