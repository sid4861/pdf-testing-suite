PDF Compare · QA Toolkit

Demo & Walkthrough

Everything the tool does, and how to use it — step by step. Two workspaces: Compare PDFs (against a reference) and Test new pages (against a JSON spec).

Note  The panels below faithfully mirror the live application — they use the app's own styles, layout, and real example data, so this file explains the app even when you can't run it.

01Two workspaces

Pick a workspace from the tabs at the top of the app.

Compare PDFs

Reference vs recreation

You have an original PDF and a recreated one, and want to prove they match.

  • Content — text diff, in-place change highlights
  • Layout — pixel diff + exact position offsets
  • Report — pass/fail across all pages, exportable
Test new pages

PDF vs JSON spec

There's no reference PDF — only a spec describing what the page should contain.

  • Checks static text, images, tables, paragraph spacing
  • Positions/sizes verified in inches, with tolerances
  • Annotated pass/fail report, exportable

03Test new pages — features

Validate a generated PDF against a JSON spec, element by element.

📝
Text checksPresent · left · top · font size · exact/contains match.
🖼️
Image checksPresent · left · top · width · height (read from the PDF's draw ops).
▦
Table checksPresent · left · top · width · row & column count.
¶
Paragraph checksPresent · left · top · measured line spacing.
🎯
Overlay visualisationExpected box (dashed) vs actual box (green pass / red fail) drawn on the page.
⚖️
TolerancesDefaults 0.06″ position / 0.06″ size / 0.03″ spacing — overridable per element.
🔎
Missing = flaggedA spec element absent from the PDF is reported NOT FOUND, never silently passed.
📤
ExportAnnotated HTML report or JSON.

Content tab — the “where”
  • Highlights on the page: every change is boxed & numbered — red on A (removed), green on B (added), violet for moved.
  • Summary chip & page strip (top): “5 of 6 pages differ”, with a dot per page (red = differs, green = identical, amber = missing). Click to jump.
  • Filter toggles (Removed / Added / Moved) hide change types; counts shown.
  • Changes list gives each change's type, text and location; hovering links it to its box on the page.
  • Jump to next / prev change skips identical pages.

Layout tab
  • Pixel diff heat-map shows exactly which pixels changed, with a % badge and a sensitivity slider. A Side-by-side view is also available.
  • Before → after tooltip: where text was replaced, hovering the changed region shows the old and new text (old struck-through in red, new in green) — as in the dark tooltip above.

  • Position-shift table lists every shared run in plain words (“12px right, 36px up”); rows above the flag threshold are highlighted. Hovering a row marks the run on the page, and vice-versa.
