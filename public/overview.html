The problem

Recreated documents fail quietly.

Templates, invoices, statements and contracts are constantly rebuilt by new systems. A single transposed number or misplaced block can reach a customer, a regulator, or the balance sheet — and manual, side-by-side checking is slow, subjective, and easy to skip under deadline.

Silent errors

Differences that the eye skips over are exactly the ones that cost the most.

Slow sign-off

Eyeballing two PDFs page by page doesn't scale and leaves no record.

No audit trail

“Looks fine to me” isn't evidence when a document is later disputed.

What it does

Three lenses on the same comparison.

Every uploaded pair is examined three ways — so a change is caught whether it's in the words, the position, or the picture.

01 — CONTENT

What changed

A word-level diff of the actual text on every page, with each change highlighted in place on the rendered pages so you see exactly where it sits.

  • Added, removed & moved text, colour-coded
  • Per-page change list with position
  • Content-match score for each page
− + ↔
02 — LAYOUT

Where it moved

A pixel-level heat-map plus exact position offsets for every text run — catching visual shifts that never touch a single character.

  • Pixel diff with adjustable sensitivity
  • Side-by-side, overlay & zoom views
  • Plain-language shift readouts (“12px right”)
03 — REPORT

Whether it passes

A roll-up across all pages against thresholds you set, with an overall pass/fail verdict and a report you can hand to anyone.

  • Set your own pass criteria
  • Per-page PASS / FAIL breakdown
  • Export to HTML, JSON or CSV

How to use it

Four steps, no training required.

Anyone who can open a web page can run a full comparison end to end.

1

Load two PDFs

Drop the original into Side A and the recreated version into Side B — or click “Load example invoices” to try it instantly.

2

Review content

The Content tab highlights every text change on the page and lists where each one is. Use “next change” to move through them.

3

Inspect layout

The Layout tab shows the pixel heat-map and position offsets. Zoom in to confirm anything that looks off.

4

Report & export

Set your pass thresholds, run all pages for an overall verdict, and export the report to share or archive.
