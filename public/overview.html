Deployment Executes entirely in the browser tab. Pixel comparison and text comparison are complementary: pixels detect what the text layer omits, text explains what the pixels show.
Dependencies

Stack

pdfjs-dist 4.7
Rasterises each page to canvas and returns every text run with box, font name and size. Both outputs feed the comparison.
pixelmatch 5.3
Per-pixel comparison with anti-aliasing suppression. Produces the heat map and the differing-area ratio.
diff 5.2
Word- and array-level differencing for intra-line highlighting and table-cell alignment.
React 18 · Zustand 4.5 Vite 5.4 · TypeScript 5.6
UI and state. A single store holds the comparison cache, thresholds and annotations.
pdf-lib · JSZip 1.17 · 3.10
Stamps review comments onto the source PDF as real annotations; bundles reports and marked-up documents.

CLI execution

The CLI imports the same engine modules as the app. One implementation, two entry points.

jenkins · stage: pdf-regression
$ pdfsuite generate --payloads ./payloads --out ./candidates 12 payloads · avg 28.4s · ETA 3m 12s ✓ 12 PDFs written to ./candidates $ pdfsuite compare --pairs pairs.json --goldens ./goldens ✓ 11 of 12 passed · 74 pages ✗ statement-q3.pdf page 4 layout 0.08in shift (14 runs) exit 1

Commands

generate posts payloads to the render API and stores responses. compare evaluates them against goldens.

Exit codes

0 pass · 1 comparison failed · 2 tool error. Separated so a pipeline can distinguish document regressions from job failures.
